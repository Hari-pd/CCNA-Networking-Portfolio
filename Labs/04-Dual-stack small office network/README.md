Dual-Stack Small office network: Understanding OSI Layers

1. Project Overview

   This project focuses on designing and implementing a dual-stack small office network using cisco packet tracer.
The network uses both IPV4 and IPV6 to demonstrate how devices communicate across different network segments through routers and switches.
The main focus is to understand how the seven layers of OSI (Open System Interconnection) model work together during end to end network communication.

2. Objectives

   * Understand the functions and responsibilities of seven layers of OSI model.
   * Understand PDUs and how data changes as it moves through the OSI layers.
   * Observe data encapsulation and decapsulation.
   * Explore TCP and UDP communication at transport layer.
   * Configure and use IPV4 and IPV6 addressing.
3. Lab Environment
Simulation tool: Cisco Packet Tracer

Network Components:
-Router
-Layer 2 Switches
-End Devices (PCs and Laptops)
-Network servers
